# RO Lounge — โปรเจกต์ตั้งต้น

เกม social hub 2D บนเว็บ แนว RO แต่ไม่มีมอนสเตอร์ เดิน แชท และ emote ร่วมกันแบบ realtime

Stack: Phaser 3 + Vite (client) · Colyseus + Node (server) · TypeScript ทั้งสองฝั่ง

## วิธีรัน (ต้องมี Node 18+)

เปิดสอง terminal

```bash
# terminal 1: เซิร์ฟเวอร์ (พอร์ต 2567)
cd server
npm install
npm run dev

# terminal 2: หน้าเว็บ
cd client
npm install
npm run dev
```

เปิด http://localhost:5173 สองแท็บ ใส่ชื่อคนละชื่อ แล้วลองคลิกพื้นเพื่อเดิน พิมพ์แชท และกดปุ่ม emote

## ทำอะไรได้แล้ว (เฟส 1–4 ในแผน)

- คลิกพื้นเพื่อเดิน เซิร์ฟเวอร์ขยับตัวละครด้วยความเร็วคงที่ กันโกง
- เห็นผู้เล่นทุกคนในห้อง ตัวละครหายเมื่อออก
- แชทลอยเหนือหัว 5 วินาที + log ด้านล่าง (จำกัด 120 ตัวอักษร, ส่งได้ทุก 0.7 วินาที)
- emote 6 แบบ
- ปรับสีเสื้อ สีผม ทรงผม สีผิว และสีกางเกงก่อนเข้าเมือง โดยจำค่าบนเบราว์เซอร์
- หน้าสร้างตัวละครแบบเลือกภาพ 24 ตัวเลือก รวมชาย/หญิงพร้อมชุดและทรงผมที่เข้ากัน ตัวอย่างตัวจริงและปุ่มหมุนดูหน้า/ข้าง/หลัง
- ฉากหลังหน้าสร้างตัวละครเจนใหม่; รูปตัวเลือกและตัวอย่างใช้สไปรต์เดียวกับตัวละครในเกม
- ตัวละครและแมพวาดด้วย pixel canvas; ฉากหลังหน้าสร้างตัวละครเป็นภาพเจน
- ตัวละครหยุดแล้วคงทิศเดิม ไม่เปลี่ยนท่าเดินจากตำแหน่งเศษพิกเซล
- แมว กระต่าย ผีเสื้อ ผึ้ง และเต่าทองเดิน/บินพักตามธรรมชาติ พร้อมอากาศแดด ฝน หิมะ
- ตกปลาได้ทุกด้านรอบริมบ่อ: รอปลาติดเบ็ด กด Spacebar/ปุ่มมือถือให้ตัวชี้ตรงแถบแดงกลางเกจ ได้ชิปสุ่ม 1–20 (รางวัลสูงออกยากกว่า) แม้ชิปหมดก็ตกได้

## ยังไม่มี

ระบบบัญชีและบันทึกตัวละครข้ามอุปกรณ์, หลายแมพ, ตัวกรองคำหยาบ, report/mute, sprite จริง

## ร้าน Boardgame — ป๊อกเด้ง

เพิ่ม guest UUID + Wallet เริ่มต้น 100 ชิป, ทางเข้า casino ที่ตรวจตำแหน่งฝั่ง server,
โต๊ะ Colyseus `pok_deng` 8 ที่นั่ง และเกมป๊อกเด้งแบบ server-authoritative
มี private hand messages, timeout, reconnect และการคิดชิปแบบ atomic
มีร้าน Boardgame พิกเซลทางขวาของน้ำพุ เดินเข้าประตูหรือกด “ไป Boardgame” เพื่อเดินไป
เลือกที่นั่งเจ้ามือ/ลูกมือ ลงเดิมพัน จั่ว/อยู่ ดูผลและชิปในหน้าจอโต๊ะได้แล้ว
ชิปฟรีเท่านั้น ไม่มีเงินจริง เจ้ามือและลูกมือสำรองสูงสุด 5 เท่าของเดิมพัน
Guest เริ่ม 100 ชิป จึงรับเดิมพัน 10 ได้พร้อมกันสองคน หากต้องการรองรับครบ 7 ลูกมือ
เจ้ามือต้องสะสมทุนอย่างน้อย 350 ชิป
กลับเข้าโต๊ะได้ภายใน 60 วินาทีเมื่อหลุด; ออกจากโต๊ะได้หลังคิดชิปและกลับสู่ช่วงเดิมพัน
ข้อมูลยังเป็น memory-only: รีสตาร์ต server แล้วชิป/Guest หาย UI จะแจ้งให้เริ่ม Guest ใหม่โดยผู้เล่นยืนยันเอง

ดู [โมดูล กติกา และ Event API](docs/pok-deng.md) สำหรับต่อกับ Phaser/UI
รันทดสอบด้วย `cd server && npm test`
ทดสอบ UI สองผู้เล่นด้วย `cd client && npm run test:e2e` (เปิด server/Vite ก่อน และติดตั้ง Chrome)
ทดสอบหน้าสร้างตัวละครด้วย `cd client && npm run test:creator`
หน้าเล่นจัดเป็นโต๊ะผ้าสักหลาดพิกเซล 8 ที่นั่ง โดยหมุนมุมมองให้เรานั่งด้านล่างเสมอ
ไพ่ส่วนตัวคลี่ในมือด้านล่าง พร้อมเอฟเฟกต์แจกจากสำรับ จั่วใบที่สาม พลิกไพ่ และไฮไลต์ผู้ชนะ
ไพ่คนอื่นยังคว่ำจนกว่า server อนุญาตให้เปิด ไม่มีไพ่กองกลางแบบโป๊กเกอร์หรือยอดกระเป๋าคนอื่นที่แต่งขึ้น
เอฟเฟกต์ไม่เล่นซ้ำตอนยอดชิปอัปเดต และเคารพ `prefers-reduced-motion`
ยอดชิปใช้เลขอ่านง่ายพร้อมหน่วยและคั่นหลักพัน เช่น `1,234 ชิป`; ตัวเลขหน้าไพ่/แต้ม/เวลาอ่านชัด แต่ภาพและกรอบยังเป็นพิกเซล การจัดรูปแบบไม่เปลี่ยนยอดจริงหรือค่าที่ส่งเดิมพัน
ทดสอบหน้าไพ่ 52 ใบด้วย `cd client && npm run test:cards`
ทดสอบโต๊ะครบ 8 คน/เอฟเฟกต์/ความเป็นส่วนตัว/จอ 320–1280px ด้วย `cd client && npm run test:table` (เปิด Vite ก่อน)
ดู [ระบบสัตว์ อากาศ และตกปลา](docs/nature-fishing.md) สำหรับวิธีเล่นและทดสอบ

## เสียงเกม

เอฟเฟกต์ต้นฉบับสไตล์พิกเซลสร้างด้วย Web Audio: เลือกตัวละคร/กดปุ่ม, เดิน, แชท/emote, เข้า–ออกร้าน,
เดิมพัน/แจก/จั่ว/อยู่/เปิดไพ่, ป๊อก 8–9, ชนะ/แพ้/เสมอ และเตือน 3 วินาทีสุดท้ายของคนที่ยังเลือกได้
มีเสียงแมว/ผึ้ง/กระต่ายใกล้ตัว บรรยากาศนก/น้ำ/ฝน/ลม และตกปลา (เหวี่ยงเบ็ด/ปลาติด/ดึง/ได้ปลา/พลาด)
เริ่มเสียงหลังผู้ใช้แตะหรือกดปุ่มครั้งแรก; ปุ่ม 🔊/🔇 อยู่หน้าสร้างตัวละคร แถบชิป และหัวหน้าจอ Boardgame
จำการปิดเสียงในเบราว์เซอร์ ไม่มีไฟล์เพลง/เสียงจากบุคคลอื่น และไม่มีการส่งเสียงหรือการตั้งค่าเสียงไปที่เซิร์ฟเวอร์
เพลง cozy ต้นฉบับ 8 ห้อง 76 BPM: คีย์นุ่ม เบสเบา เมโลดีโปร่ง เล่นวนตอนอยู่ในเมือง/Boardgame ด้วย mixer เดียว
เริ่มความดังเพลง 20% (ต่ำกว่าเอฟเฟกต์) ปุ่ม 🎵 ที่หน้าสร้างตัวละคร แถว emote และหัวโต๊ะ ปรับ 0–100% หรือปิดเฉพาะเพลงได้
เพลงจำระดับเสียง/การปิดแยกจากเอฟเฟกต์; 🔇 ปิดทุกเสียง เพลงไม่เริ่มก่อน gesture/เข้าเมือง และหยุดเมื่อซ่อนแท็บ/หลุดการเชื่อมต่อ
เมื่อซ่อนแท็บหรือปิดเสียงจะหยุดเสียงและบรรยากาศ เข้าร้านแล้วหยุดเสียงแมพ ไม่ทับเสียงซ้ำตอน state/wallet อัปเดต
เสียงป๊อกอ่านเฉพาะ HandValue ที่เซิร์ฟเวอร์เปิดเผยแล้ว ไม่บอกไพ่ลับของคนอื่นและไม่เล่นผลเก่าซ้ำเมื่อ reconnect
ทดสอบด้วย `cd client && npm run test:sound` (เปิด Vite ก่อน): วัด waveform จริง, การ mute/จำค่า/หยุดเมื่อซ่อนแท็บ,
เสียงทั้ง 31 แบบ, lifecycle ของ audio nodes, ความเป็นส่วนตัวและการไม่เล่นซ้ำ, storage ที่ถูกปิดและอุปกรณ์ที่ไม่มี Web Audio
ทดสอบเพลงครบ loop/วัดความเบา/จำค่า/แยก mute อยู่ใน `test:sound`; `npm run test:music-live` ทดสอบเข้าเมือง/เข้าร้านจริงแบบผู้ชม ไม่เดิมพัน
ใช้ `RO_TEST_URL=https://ro-lounge.vercel.app npm run test:music-live` ตรวจเวอร์ชันที่ deploy แล้ว

## ตอน deploy

ตั้งตัวแปร `VITE_SERVER_URL` (เช่น `wss://your-game-server.fly.dev`) ตอน build ฝั่ง client
เซิร์ฟเวอร์ต้องรันเป็นโปรเซสค้าง (Fly.io, Railway, VPS) ไม่ใช่ serverless

## ขึ้นออนไลน์ให้เพื่อนเล่น

1. ดันโปรเจกต์ขึ้น GitHub (repo เดียว มีโฟลเดอร์ server กับ client)
2. **เซิร์ฟเวอร์เกม** (Railway หรือ Render): ชี้ไปที่ repo ตั้ง Root Directory = `server`,
   Build = `npm install`, Start = `npm start` ได้ URL เช่น `https://xxx.up.railway.app`
   ตรวจว่าเปิด `https://xxx.../health` แล้วขึ้น `ok`
3. **หน้าเว็บ** (Vercel, Netlify หรือ Cloudflare Pages): ตั้ง Root Directory = `client`,
   Build = `npm run build`, Output = `dist` และตั้ง Environment Variable
   `VITE_SERVER_URL=wss://xxx.up.railway.app` (ใช้ wss:// ไม่ใช่ https://) ก่อน build
4. ส่งลิงก์หน้าเว็บให้เพื่อน

หมายเหตุ: แพ็กเกจฟรีบางเจ้า (เช่น Render) จะหลับเมื่อไม่มีคนใช้ เปิดครั้งแรกอาจรอ 30–60 วินาที
