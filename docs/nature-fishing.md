# Living town: สัตว์ อากาศ และตกปลา

- Server สร้างสัตว์ 13 ตัว: แมว 3, กระต่าย 3, ผีเสื้อ 3, ผึ้ง 2, เต่าทอง 2
- เดิน/บินรอบจุดบ้าน หยุดพัก สุ่มจุดใหม่ และไม่เดินผ่านน้ำ น้ำพุ ตัวบ้าน หรือต้นไม้
- ตำแหน่ง/การพักของสัตว์ซิงก์ผ่าน Colyseus; การกระพือปีก/กระโดดเป็น cosmetic ฝั่ง client
- อากาศในห้องเดียวกันตรงกัน เปลี่ยน sunny → rain → snow ทุก 120 วินาที
- ฝนมีแสงมืดลงและวงกระเพื่อมบ่อ; หิมะมีเกล็ดลอย; แดดมีแสงอุ่น
- จำกัดอนุภาคตามขนาดจอ (55 บนมือถือ, 95 บน desktop) และ update สัตว์ 10 Hz

## วิธีตกปลา

เดินใกล้ป้ายริมบ่อ หรือกด “ไปบ่อตกปลา” เพื่อเดินอ้อมไปริมฝั่ง
กดเริ่มตกปลาหรือ Space รอ 4–8 วินาที เมื่อขึ้น “ปลากินเหยื่อ” ให้กด Space
หรือปุ่มดึงเบ็ดบนมือถือให้ทันภายใน 3 วินาที
กดก่อนปลากินหรือช้าเกินไปไม่ได้ปลา กดซ้ำไม่เพิ่มปลา เก็บเบ็ดหรือเดินออกเพื่อยกเลิก
Space ไม่รบกวนการพิมพ์แชทหรือชื่อตัวละคร

ปลา 4 ชนิดพร้อมขนาดสุ่ม เซิร์ฟเวอร์เป็นผู้ตัดสินและบันทึกกระเป๋าปลา
จับสำเร็จแต่ละตัวได้รับ **10 ชิปฟรีทันที** เข้ากระเป๋าป๊อกเด้ง แม้ชิปเหลือ 0 ก็เริ่มตกปลาได้
เซิร์ฟเวอร์ตรวจจังหวะและเพิ่มชิปครั้งเดียวต่อ castId; กดก่อน/ช้า/ยกเลิก/ส่งซ้ำไม่ได้ชิป
ไม่มีเงินจริง ไม่ต้องขายปลาเอง จำนวนปลาและชิปจำตาม Guest UUID เดิมแม้รีเฟรช
แต่ยังเป็น memory-only หายเมื่อ server restart
โต๊ะป๊อกเด้งยังสำรองสูงสุด 5 เท่าของเดิมพัน: เดิมพันขั้นต่ำ 10 ต้องมี 50 ชิป (ปลา 5 ตัวจากยอด 0)

## API

| Client → Server | Payload |
| --- | --- |
| `nature:sync` | `{}` ขออากาศกับเวลา server |
| `fish:sync` | `{}` ขอสถานะเบ็ดและกระเป๋าปลา |
| `fish:cast` | `{}` server ตรวจพิกัดจริงใกล้ป้าย, ไม่อยู่ casino, ไม่มีเบ็ดอีก connection |
| `fish:reel` | `{ castId }` server ตรวจผู้เล่น, connection เจ้าของ, รอบเบ็ด, จังหวะจริง |
| `fish:cancel` | `{}` เก็บเบ็ดของ connection นี้ |

Owner-only: `fish:state` มี phase, castId, deadline, serverTime, กระเป๋าและผล (รวม rewardChips)
`wallet:update` ส่งยอดใหม่ทันทีเมื่อได้ปลา; client ไม่เป็นผู้กำหนดจำนวนรางวัล
ไม่ส่งเวลาปลาจะกินเหยื่อล่วงหน้า ข้อผิดพลาดผ่าน `api:error`
Public schema มีสถานะตกปลา/จุดตกปลา เพื่อให้คนอื่นเห็นเบ็ดและทุ่น แต่ไม่มี castId หรือ inventory
การเดิน เข้า casino หลุด หรือปิดแท็บยกเลิกเบ็ด; ปลาที่จับสำเร็จแล้วไม่ถูกลบ

## ทดสอบ

`cd server && npm test`: กติกาอากาศ สัตว์ collision เวลา/จังหวะ/สิทธิ์ตกปลา และ regression เดิม

Local browser QA:

1. `cd server && RO_WEATHER_PHASE_MS=5000 npm start` (เฉพาะ QA; production ใช้ default)
2. `cd client && npm run dev`
3. `cd client && npm run test:nature`

บน production: `E2E_URL=https://ro-lounge.vercel.app npm run test:nature`
ไม่เร่งอากาศหรือแก้เวลาใน client เพื่อให้ผ่านการทดสอบ
